# Сопроводительное письмо для hh.ru

Chrome-расширение создаёт персональное сопроводительное письмо по открытой вакансии hh.ru и выбранному TXT-резюме через API-ключ пользователя.

## Возможности

- читает название, компанию, описание и ключевые навыки со страницы вакансии;
- хранит несколько TXT-резюме и позволяет выбрать нужное перед генерацией;
- поддерживает OpenAI API, OpenRouter API, DeepSeek API и Claude API (Anthropic);
- позволяет выбрать предложенную модель или вручную указать любой ID модели;
- поддерживает деловой, дружелюбный и краткий тон, а также дополнительные пожелания;
- показывает результат для редактирования, копирования и вставки в форму отклика;
- никогда не отправляет отклик автоматически.

## Установка

1. Скачайте или клонируйте репозиторий.
2. Откройте в Chrome страницу `chrome://extensions`.
3. Включите «Режим разработчика».
4. Нажмите «Загрузить распакованное расширение».
5. Выберите папку проекта.

Сборка и установка зависимостей не требуются.

## Настройка

### 1. API

Откройте вкладку «API» в расширении:

1. выберите провайдера;
2. вставьте собственный API-ключ;
3. выберите предложенную модель или введите её ID;
4. нажмите «Сохранить настройки».

Настройки ключей сохраняются отдельно для каждого провайдера. Активным считается последний сохранённый провайдер.

### 2. Резюме

На вкладке «Резюме» загрузите один или несколько файлов `.txt`. Ограничения:

- до 1 МБ на файл;
- до 5 МБ суммарно;
- пустые файлы не принимаются.

TXT можно получить из любого текстового редактора. Лучше сохранять обычную структуру: имя, специализация, опыт, достижения, навыки и образование.

## Генерация

1. Откройте страницу вида `https://hh.ru/vacancy/...`.
2. Откройте расширение.
3. Выберите резюме и тон письма.
4. При необходимости добавьте пожелание к тексту.
5. Нажмите «Создать и вставить».

Если форма отклика уже открыта, результат будет вставлен в поле сопроводительного письма. Иначе текст останется в редакторе расширения — его можно скопировать или вставить после открытия формы.

## Данные и безопасность

- API-ключи и резюме хранятся в `chrome.storage.local` на текущем устройстве и не синхронизируются через аккаунт Chrome.
- Ключи не передаются на hh.ru и не добавляются в DOM страницы.
- При генерации текст выбранного резюме и вакансии отправляется выбранному API-провайдеру.
- Используйте API-ключ с минимальными правами и установленным лимитом расходов.
- Удаление расширения удаляет его локальное хранилище.

Обработка данных на стороне API регулируется условиями и политикой выбранного провайдера.

## Архитектура

- `manifest.json` — Manifest V3, разрешения API-хостов и точки входа;
- `popup.html`, `popup.css`, `popup.js` — интерфейс, загрузка резюме и сценарий генерации;
- `content.js` — чтение вакансии и вставка текста в форму hh.ru;
- `background.js` — запросы к API и единый системный промпт.

API-запросы выполняются из service worker. Для OpenAI используется Responses API, для Claude — Messages API, для OpenRouter и DeepSeek — Chat Completions API.

## Разработка

После изменения файлов нажмите кнопку обновления у расширения на странице `chrome://extensions`, затем перезагрузите вкладку с вакансией.

Селекторы hh.ru собраны в объекте `SELECTORS` в `content.js`. При изменении разметки сайта их можно обновить в одном месте.
